# Frontend

React + TypeScript + Vite application for Knowra.

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # production bundle in dist/
```

Configure `VITE_API_BASE_URL` via `.env` (see `.env.example`).
